# PhotoFit - Passport Photo Resizer & Compressor

## About the Project
PhotoFit is a web-based application that helps users resize and compress passport-size photographs according to selected dimensions and file size limits.

## Features
- SSC, UPSC and NEET presets
- Custom dimensions
- Custom KB limits
- Photo upload and preview
- Automatic image resizing
- JPG and PNG formats
- Automatic JPG compression
- Before-and-after comparison
- Download processed photos

## Technologies Used
- HTML
- CSS
- JavaScript
- HTML5 Canvas API

## How to Run
1. Open the project folder.
2. Double-click index.html.
3. Upload a photograph.
4. Select a preset.
5. Choose JPG or PNG.
6. Click Resize & Compress Photo.
7. Download the processed image.

## Objective
To develop an easy-to-use photo resizing and compression tool for online application requirements.
